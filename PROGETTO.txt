================================================================================
PROGETTO: Analisi Documento — AI Tool per portfolio di Alessandro Dardi
================================================================================

SCOPO
-----
Tool web che analizza qualsiasi documento aziendale (preventivi, contratti,
email commerciali, bandi) e restituisce in pochi secondi una sintesi strutturata
in 5 sezioni: Sintesi, Cosa include, Punti di attenzione, Condizioni chiave,
Domande da fare.

Fa parte del portfolio di Alessandro Dardi (Operations & Service Manager, Bologna).
Portfolio: https://alessandrodardi-1982.github.io/portfolio/

PRINCIPI PROGETTUALI
--------------------
- Privacy-first: nessun dato salvato su server, nessun database
- Zero backend: funziona su GitHub Pages puro (static hosting)
- Modalità Demo (default) + Modalità Live (con API key Anthropic dell'utente)
- "AI suggerisce, umano decide" — output sempre revisionabile
- Applicabile a qualsiasi settore aziendale (non verticale su un solo mercato)

ARCHITETTURA TECNICA
--------------------
Tipo:        Single-page HTML (un file unico, self-contained)
Hosting:     GitHub Pages (statico, zero costi)
Backend:     Nessuno — la chiamata API parte direttamente dal browser
API AI:      Anthropic Claude (modello: claude-haiku-4-5)
Autenticazione API: chiave inserita dall'utente, salvata in localStorage
             (non transita per nessun server intermedio)
Font:        Google Fonts — Inter (400, 500, 600, 700)
Librerie JS: nessuna (vanilla JS puro)

FUNZIONAMENTO
-------------
MODALITÀ DEMO (default, senza API key):
  - L'utente carica uno dei 4 esempi precaricati cliccando i bottoni
  - Clicca "Analizza documento"
  - Viene mostrata un'animazione di caricamento simulata (~2 secondi)
  - Appare l'analisi pre-scritta corrispondente all'esempio
  - Badge "Demo · dati simulati" visibile in testa ai risultati

MODALITÀ LIVE (con API key):
  - L'utente clicca "⚙ API Key" in alto a destra
  - Incolla la sua chiave Anthropic (sk-ant-...)
  - La chiave viene salvata in localStorage con key "analisi_doc_apikey"
  - Il badge in alto cambia da "Demo" (grigio) a "Live" (verde)
  - Al click su "Analizza documento" viene chiamato:
    POST https://api.anthropic.com/v1/messages
    Headers: x-api-key, anthropic-version: 2023-06-01,
             anthropic-dangerous-direct-browser-ipc: true
    Model: claude-haiku-4-5 — max_tokens: 1500
  - Claude restituisce JSON strutturato (estratto via regex dal testo)
  - Badge "⚡ Analisi live · Claude AI" visibile in testa ai risultati

STRUTTURA OUTPUT (JSON atteso da Claude)
-----------------------------------------
{
  "title": "titolo descrittivo max 60 caratteri",
  "meta": "tipo · valore economico · data",

    "condizioni": [{"k": "nome", "v": "valore", "flag": true|false}, ...],
    "domande": ["domanda 1", "domanda 2", ...]
  }
}

UX E COMPORTAMENTO
------------------
- All'apertura: hint arancione animato ("Carica uno degli esempi") + bottoni pulsanti
- Hint scompare appena viene caricato un esempio o l'utente inizia a scrivere
- Pulsante "✕ Cancella testo" (rosso, con bordo) appare sotto la textarea
  quando c'è testo; scompare quando è vuota
- Loading bar animata durante l'analisi con messaggi di stato progressivi
- Sezioni risultati collassabili (accordion), prima sezione aperta di default
- Pulsante "Copia analisi" → copia testo pulito (senza HTML) negli appunti
- Pulsante "↩ Nuova analisi" → resetta tutto e torna all'inizio
- Toast notification per conferme e errori

TEMA / DESIGN
-------------
- Light mode default, dark mode completo via prefers-color-scheme + data-theme
- Palette: blu notte (#1d3557) primario, arancione (#d9622b) accent
- Token CSS su :root, tutti i colori derivati da variabili
- Layout: max-width 780px, padding laterale 16px, mobile-first

PRIVACY
-------
- Nessun cookie, nessun tracking
- API key salvata solo in localStorage del browser dell'utente
- Testo del documento inviato solo ad Anthropic API (con DPA)
- Nessun server intermedio in modalità live
- Nota privacy visibile in fondo alla pagina con link a informativa Anthropic

UX DETTAGLI AGGIUNTIVI
----------------------
- Hint arancione animato (freccia su + testo) visibile quando textarea è vuota;
  scompare appena si carica un esempio o si inizia a digitare
- I 4 bottoni esempi pulsano leggermente (animazione CSS) finché textarea è vuota
- Pulsante "✕ Cancella testo" rosso con bordo appare sotto la textarea quando
  c'è testo; scompare quando la textarea è vuota; pulisce textarea, risultati
  e stato corrente
- Su mobile: titolo, testo descrizione, pillole benefici e bottoni esempi
  sono tutti centrati per un layout più bilanciato
